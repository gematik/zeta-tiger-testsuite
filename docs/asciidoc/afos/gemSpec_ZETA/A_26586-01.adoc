==== A_26586-01 - PDP Authorization Server - Session-Daten

Die Komponente Authorization Server MUSS nach jeder vollständigen und erfolgreichen Authentifizierung Session-Daten in der Datenbank des PDP speichern. Zu den Session Daten gehören die Client-, User, und Request-Daten gemäß [policy-engine-input.yaml].
