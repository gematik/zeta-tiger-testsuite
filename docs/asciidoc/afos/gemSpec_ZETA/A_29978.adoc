==== A_29978 - Notification Service – Bindung von Operationen an den authentisierten Nutzer

Der Notification Service MUSS Schreib-/Leseoperationen des Client-Moduls (Registrierung, Schlüssel, Channel-Konfiguration eines Pushers) ausschließlich auf die im ZETA-Zugriffstoken authentisierte Nutzeridentität beziehen und MUSS Operationen auf Pusher/Daten anderer Nutzer mit 403 ablehnen. [<=]
