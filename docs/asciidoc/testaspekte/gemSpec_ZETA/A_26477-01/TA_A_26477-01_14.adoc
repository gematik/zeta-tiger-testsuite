===== TA_A_26477-01_14 - PoPP Token Validierung - Kulanz am Quartalswechsel

"[...] Bei einem Prüfzeitpunkt innerhalb des gleichen Quartals MUSS eine **grace-period von 5 Minuten beim Quartalswechsel** akzeptiert werden. [...]"

Alle übrigen konfigurierten Prüfungen einschließlich einer zusätzlich begrenzten maximalen Gültigkeitsdauer müssen erfüllt sein.
