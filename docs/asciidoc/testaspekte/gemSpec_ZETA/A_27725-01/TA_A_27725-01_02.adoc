===== TA_A_27725-01_02 - ZETA Guard, Telemetriedaten Service, Status Codes - Authentifizierung mit Client Assertion JWT - 400 Bad Request

Der Telemetriedaten Service im ZETA Guard MUSS im Parameter *http.response.status_code* einen konkreten 3-stelligen HTTP-Statuscode gemäß Tab_gemSpec_ZETA_Telemetriedaten_HTTP_Statuscodes übermitteln.

Dieser Testaspekt fokussiert die in <<A_27007>> spezifizierte Variante *Authentifizierung mit Client Assertion JWT* mit dem Statuscode *400 Bad Request*.
