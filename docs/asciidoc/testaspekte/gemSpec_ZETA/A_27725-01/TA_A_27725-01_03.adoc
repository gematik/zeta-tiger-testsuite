===== TA_A_27725-01_03 - ZETA Guard, Telemetriedaten Service, Status Codes - Authentifizierung mit Client Assertion JWT - 401 Unauthorized

Der Telemetriedaten Service im ZETA Guard MUSS im Parameter *http.response.status_code* einen konkreten 3-stelligen HTTP-Statuscode gemäß Tab_gemSpec_ZETA_Telemetriedaten_HTTP_Statuscodes übermitteln.

Dieser Testaspekt fokussiert die in <<A_27007>> spezifizierte Variante *Authentifizierung mit Client Assertion JWT* mit dem Statuscode *401 Unauthorized*.
