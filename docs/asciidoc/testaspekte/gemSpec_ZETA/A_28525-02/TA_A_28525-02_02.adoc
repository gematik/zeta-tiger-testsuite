===== TA_A_28525-02_02 - Step-up bei unzureichendem Authentifizierungsniveau

Die Komponente HTTP Proxy MUSS dem Client Step-up-Bedarf mit **HTTP-Statuscode 401 (Unauthorized)** und einem WWW-Authenticate-Header gemäß [RFC9470] signalisieren, wenn eine der folgenden, durch eine erneute (Step-up-)Authentisierung behebbaren Bedingungen vorliegt: **das im gültigen Access Token (Claim acr) nachgewiesene Authentifizierungsniveau erreicht nicht das für die aufgerufene Route konfigurierte Mindest-acr**, oder der im gültigen Access Token (Claim scope) enthaltene Scope deckt den für die aufgerufene Route konfigurierten erforderlichen Scope nicht ab, dieser ist aber über eine erneute (Step-up-)Authentisierung erlangbar. Der WWW-Authenticate-Header MUSS den zutreffenden Fehlercode enthalten: **bei unzureichendem Niveau error="insufficient_user_authentication" mit den Parametern acr_values (und ggf. max_age)**; bei unzureichendem Scope error="insufficient_scope" mit dem Parameter scope. Sind beide Bedingungen erfüllt, MUSS error="insufficient_user_authentication" verwendet werden (das höhere Niveau schließt die Scope-Erlangung ein). Die angefragte URL MUSS existieren und einer konfigurierten Route (mit hinterlegter logischer Audience, erforderlichem acr und erforderlichem Scope) zugeordnet sein.

Die existierende Route verlangt ein durch erneute Authentisierung erreichbares Mindestniveau; das Token und der erforderliche Scope sind ansonsten gültig.
