===== TA_A_29850_01 - PEP HTTP Proxy - Kennzeichnung eines PEP-Fehlers mit HTTP 401

"Tritt im PEP HTTP Proxy ein Fehler auf, der zu dem HTTP-Statuscode **401** führt, MUSS der HTTP Proxy der HTTP-Antwort an den ZETA-Client den folgenden HTTP-Header hinzufügen:

* Header-Name: **``zeta-error-origin``**
* Header-Wert: **``pep``**
