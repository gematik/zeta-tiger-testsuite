===== TA_A_25752-01_01 - PDP Policy Engine - Ablehnungsgründe an den Client übergeben

"Falls ein Client beim Token Request nicht die geforderten Parameter der Policy unterstützt bzw. das geforderte Niveau nicht erreicht, **MUSS der Authorization Server die von der Policy Engine in der Decision-Response aufgeführten Gründe (Attribut reasons) in der Response an den Client übergeben.** **[<=]"**
