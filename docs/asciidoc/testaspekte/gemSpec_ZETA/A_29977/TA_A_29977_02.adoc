===== TA_A_29977_02 - Notification Service - Ablehnung eines ungültigen DPoP-Besitznachweises

"Der Notification Service MUSS sicherstellen, dass das ZETA-Zugriffstoken sender-constrained ist (z. B. via DPoP oder mTLS-gebundenem Token gemäß den ZETA-Vorgaben) und DARF ein Token NICHT akzeptieren, dessen Nachweis der Besitzbindung (Proof-of-Possession) fehlt oder **ungültig ist**. **[<=]**"
